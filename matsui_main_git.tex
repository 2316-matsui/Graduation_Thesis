\chapter{はじめに}
\section{背景}
近年、独居高齢者世帯の増加や高齢化の進行、防犯・安全意識の高まりを背景として、屋内での状態把握、いわゆる「見守り」の重要性が高まっている。見守りを実現する主流な手段としてカメラ型・センサー型の機器があるが、室内への常時設置には次の三つの課題がある。
第一に、プライバシー侵害のリスクである。浴室や寝室などのプライベート空間への設置が困難である。
第二に、死角と環境依存のリスクである。夜間や暗所では精度が低下し、湯舟などは死角になりやすい。
第三に、設置コストのリスクである。新規機器の購入が必要であり、全室をカバーするには多数の機器を設置しなければならない。実際、介護家族を対象とした調査では、見守りサービスに約半数が関心を示す一方で、利用率は約5\%にとどまっている。

これらの課題を補完する技術として、Wi-FiのCSI（Channel State Information）を用いたセンシングが注目されている。
CSIは、Wi-Fi通信における伝送路特性を示すデータであり、送受信機間の空間の揺らぎを電波の振幅・位相の変化として捉えることができる。
この手法は、ほぼすべての家庭に既に設置されているWi-Fiルータを活用できるため、カメラ型に比べて導入コストの面で有利であり、映像を扱わないためプライバシーへの懸念も少ない。

本研究の目的は、家庭用Wi-Fiルータがどの程度の精度でセンシング可能かを明らかにすることである。


\section{先行研究}
先行研究では、市販ルータを送信機、ESP32マイコンを受信機として屋内の人物行動を検知するデータセットを構築した例や、同様の構成でCSIのパケットロスを復元する手法を提案した例が報告されている。
しかし、家庭用ルータを送信機とした場合に、どの程度の精度でセンシングが可能かを、マイコン送信機と比較して評価した研究は十分に行われていない。

専用機器を前提とした手法が家庭にある機器でそのまま通用するとは限らないため、実用化に向けてはこの差を把握する必要がある。
